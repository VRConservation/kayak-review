# Paddles
A DRAFT/INCOMPLETE summary of types of paddles available and their pluses and minuses. Note that these are paddles NFKCC club members use and have recommended. It is, nor will ever be, a comprehensive list. Sticks are Greenland paddles. Although not mentioned as a plus for Greenland paddles, all work exceptionally well into a headwind.

| PADDLE | TYPE | PLUS | MINUS |
|:-------|:-----|:-----| :---- |
| **Celtic** | 
| Omega  | carbon | powerful, stiff, responsive | questionable durability      |
| N12 650 | nylon | stiff, responsive but plastic for rocks | heavy  |
| **Gara** | 
| Odin | race | price, fast, powerful | not great in rough water, thin shaft  |
| **Werner** | 
| Kalliste | carbon | light, simple, great in wind | can flutter if stroke not correct |
| **Sticks** |
| DIY | wood | very light, customized | single shaft hard to stow as a second |
