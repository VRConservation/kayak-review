# Summary
I purchased this radio after the Standard Horizon radio failed and really like it. It's easy to turn on, cycle through needed channels, save favorite channels, and has waterproof access for the usb-c charging port. My only niggle is the long antenna, which is really a plus as well since, presumably, that means it has longer range.

I've only had the radio for 9 months since the SH radio fail, so we'll see how it stands up to long-term use and if it is really waterproof.

# Buyer
Any one who goes on the water.
